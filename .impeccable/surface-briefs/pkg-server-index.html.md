## Scope & mode
Surface: pkg/server/index.html (whole dashboard). Mode: Operate. Replacement world:
the incumbent graphite+teal glassy-card look is discarded evidence, not a base.

## Audience, job, action
A user, evening living room, phone + laptop. Job: one-glance "is anything wrong?",
then drill into the culprit (device, band, time). Constraints: keep every behaviour
(SSE live updates, tabs, filters, modals, uPlot charts, PWA); no external runtime deps;
self-hosted fonts only.

## Chosen direction
"Machined instrument" (code-led, seed: none (unavailable)). The page is one control
unit machined from warm dark aluminum, not a grid of floating rounded cards. Engraved
hairline rules replace card borders. A full-width status LAMP BANK (WAN · Wi-Fi mesh ·
SQM · Satellites) of labelled indicator lamps answers "is anything wrong" in one second;
hovering a lamp shows the last event that changed it (signature interaction). Live
throughput renders as a paper-tape strip chart with a large mono readout. Eyebrow/
kicker labels above headings are banned: headings carry their own weight. Memorable
moment: the lamp bank + tape readout feel like a real appliance, not a website.

## Unresolved decisions
None blocking; finish review arbitrates craft-floor violations.

## Direction contract

same-size glassy cards, uppercase tracked eyebrows and neon accent glow.
OWN-WORLD: warm charcoal-aluminum face (#1f1e1b) on a darker surround; enamel ink
(#ece9e2); regions cut by engraved groove/ridge rule pairs; seamed recessed wells for
readings; incandescent lamps (green/amber/red, no glow) always paired with state words;
Overpass UI, Spline Sans Mono for every measurement; one signal-amber ink (#e0a458) for
live data and selection. Daylight rendition: the same unit in warm paper-aluminum.
STORY: The user sees in one second whether anything is wrong (lamp bank), reads the live
line (tape + readout), then drills into the owning tab from the lamp or check.

Router · each satellite · summary); bezel tab rail; throughput instrument — 32px mono
down/up readout left, full-width paper-tape uPlot right (5M live / 3H / 24H).
